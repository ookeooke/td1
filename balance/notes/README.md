# Balance Notes

Raw balance knowledge that is useful but not yet canonical.

Use this folder for:

- playtest notes
- external research summaries
- temporary hypotheses
- screenshots or transcripts summarized into text
- audit TODO lists
- design questions that are still open

Rules:

- `balance/BALANCE.md` remains the canonical design-intent document.
- Notes here may be messy, provisional, or contradictory.
- Promote a note into `BALANCE.md` only when it becomes a real rule or target.
- Keep structured run evidence in `balance/snapshots/` when possible.

Suggested filenames:

- `YYYY-MM-DD_playtest_<topic>.md`
- `YYYY-MM-DD_research_<topic>.md`
- `YYYY-MM-DD_audit_<topic>.md`
